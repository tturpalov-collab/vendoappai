On arrival — record before touching anything

  1. Signal strength shown on the terminal (bars or dBm). Write the number down.
  2. Mobile operator and whether the SIM is roaming.
  3. Any error or warning on screen.
  4. Firmware version.

Then check, in this order

  1. Antenna: connected, undamaged, not pressed against metal or inside the cabinet.
  2. SIM: seated firmly, data plan active, not expired.
  3. Power: stable supply, no shared circuit with a compressor or motor.
  4. Run a test payment. Write down the response code, not just pass/fail.

Priority 3 Machines that stopped selling

These four were working and earning, then went quiet. In the two largest cases the terminal stopped reporting to the network one to two days after the last sale — which usually means the machine was switched off or moved, not that the software failed. First question on site is simply: is the machine still there?

Answer these four, in order

  1. Is the machine physically at the address? If not, where did it go and who moved it?
  2. Is it powered on? Check the socket and the breaker, not only the machine.
  3. Is there stock loaded? An empty machine takes no payments.
  4. Does the screen show an error, or is it simply dark?

Before you leave

  1. Run one test payment and record the response code.
  2. Confirm the terminal appears online in the back office.
  3. If the machine was removed from site, report the new location so it can be taken off the active list.
